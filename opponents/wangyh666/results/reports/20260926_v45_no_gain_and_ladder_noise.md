>

> ① **天梯对"同码两次提交"的散布实测是 61–675 分（中位 380）**，
>    而 adv4→adv8 的线上差只有 **224**——**这个差异在天梯的噪声里，不能当证据。**

## 1. 决定性控制组：同码重投的分数散布

这是本次分析里最重要的一张表。历史上我们**故意重投过同样的代码**：

| 同一份代码的两次提交 | A | B | \|A−B\| |
|---|---|---|---|
| `v23_c7` 原投 vs re-roll | 2452.2 | 1776.9 | **675** |
| `v37` 原投 vs re-roll（描述里写明"identical v37 code"） | 1679.7 | 2289.2 | **609** |
| `v36` 原投 vs 重投（描述里写明"measures v36's draw variance"） | 2472.2 | 2320.7 | **152** |
| `v24` 原投 vs rerun（描述里写明"same … code, fresh r…"） | 2272.3 | 2333.9 | **62** |

⇒ **同码 |Δ| = 61 / 151 / 609 / 675，中位 380。**

我们这次的版本差：

- v40 (adv4) 2476.6 · v41 (adv4) 2442.2 · v44 (adv6) 2244.0 · v45 (adv8) 2252.7
- **adv4 → adv8 的差 = 224**（2476.6−2252.7）——**落在同码散布之内，甚至低于中位数。**

**⇒ 不能从天梯分数断言 adv6/adv8 比 adv4 差。** 我昨晚基于"单调"给出的解读是错的。

> 顺带更正 `local_findings` 的旧标定："同版本抽签极差 ≈ 144"（V1）。
> 那是从 v36 的四次抽签算的，但**那四次的实际数值（2472/2517/2499/2373）在提交历史里对不上**
> ——历史里 v36 只有 2472.2 与 2320.7 两次。**V1 这条应当用上面四个同码对（61–675）替换。**

## 4. 机制假说：`_ADV` 是**竞赛层**，只在对手也抢跑时才赚

层的设计前提（读码）是"对手跑同一份磁带、也要卖同样的东西，先卖的人拿高价"。
对手**不抢跑**时，提前卖就是自伤：同一批货更早、更低价卖掉，没人接盘，
而这个游戏的价格**整季是上行的**（`M3`）。

**哪些对手带 `_ADV`（本地可查）**：
`tetsutani_cha22`(3) / `v52`(3) / `v53` / `beatv48` / `v50` / `v51` / `v49branch` / `tetsu_market` / `guruv4`
**哪些不带**：`v55` / `v56` / `pipe16` / `hybrid2965`（= 我们自己的近亲族） / `fieldcraft` / `herdsafe`

## 5. 天梯的对手构成（决定净收益的那一项）

按开局指纹分类（`scripts/ladder_mix.py`）：

| | v41 (adv4, 2442) | v45 (adv8, 2253) |
|---|---|---|
| **抢跑族**（tetsutani 51%/28% + v50线 + 我方血缘） | **59%**，我们胜率 50% | 37%，我们胜率 54% |
| **不抢跑族**（v4x 20/15 + herdsafe 8/3） | 25%，我们胜率 74% | 45%，我们胜率 76% |

**⇒ 档次越高，场里抢跑族越多**（v41 在高档位遇上 51% 的 tetsutani 族）。

**对 tetsutani 族单独的对照**（控制对手类型）：

| | n | 我们胜率 | 对手分 均值/中位 | 最差 4 局 |
|---|---|---|---|---|
| v41 (adv4) | 61 | **49%** | 2117 / 2452 | −6681 / −6330 / −3603 / −1854 |
| v45 (adv8) | 30 | **60%** | 1896 / 2047 | −2915 / −973 / −954 / −908 |

⇒ **方向与本地一致**：adv 越大，对抢跑族赢得越多（49% → 60% → 75%）。
但 v41 面对的对手**更强**（中位 2452 vs 2047），所以这条对照**被档位混杂**，只能当同向证据。

## 6. 决定性的对照：**对手不抢跑时，adv 越大越亏**

`adv4 / adv6 / adv8` × 4 个 **不带 `_ADV`** 的对手 × 250 种子双座位 = **500 局/格**（全 12 格）：

| 对手（都不抢跑） | adv4 | adv6 | adv8 |
|---|---|---|---|
| `v55`（我方近亲族） | 97.4% / +$1644 | 97.0% / +$1567 | 97.4% / +$1457 |
| `hybrid2965` | 93.4% / +$673 | 93.0% / +$802 | 93.0% / +$911 |
| `fieldcraft` | 85.2% / +$2408 | 86.8% / +$2439 | **87.0%** / +$2590 |
| `herdsafe`（保畜族，新入面板） | **95.2%** / +$1192 | **90.0%** / +$1090 | **89.4%** / +$1030 |

**四个里三个完全无差**（`v55` 逐位持平、`hybrid2965` 逐位持平、`fieldcraft` 反而**随 adv 上升** 85.2→86.8→87.0）。
**只有 `herdsafe` 一格掉，而且是单调的**：95.2% → 90.0% → 89.4%。

**大跌在 4→6（−5.2pp），6→8 只剩 −0.6pp**；adv4 vs adv8 的 −5.8pp 两比例 z≈3.5（p≈0.0005）。

对照同一批种子打**抢跑族**（`tetsutani_cha22`，它带 `_ADV_LOOK=3`）：
adv4 ≈48% → adv8 **85.4%**，**+37pp**。

**⇒ 竞赛假说成立，而且比预期更干净**：`_ADV` 在对手抢跑时是大赚（+37pp），
在对手不抢跑时**基本无影响**（4 个里 3 个为 0，1 个 −5.8pp）。

### 6.1 按天梯的对手构成折算净收益

用 `scripts/ladder_mix.py` 量到的构成（**v41 的档位**：抢跑族 59%、不抢跑族 25%、其它 16%）。
平均胜率按四个不抢跑对手取平均：adv4 92.8% → adv8 91.7%（**−1.1pp**）。

```
adv4 → adv8 :  0.59 × (+37.4)  +  0.25 × (−1.1)  +  0.16 × 0  ≈  +21.8pp
adv8 → adv12:  0.59 × (+7.7)   +  0.25 × (−1)    +  0.16 × 0  ≈  +4.5pp
```

⇒ **按构成折算，adv12 相对 adv4 在线上应当净赚 ~26pp 胜率。** 这与"天梯那 224 分是噪声"（§1）一致。

### 6.2 线上其实**看得见**这个提升——只是不在分数里

| | v41 (adv4) | v45 (adv8) |
|---|---|---|
| 总胜率 | 59.6% (109 局) | **70.2%** (94 局) |
| 对 `tetsutani` 族胜率 | 49% (n=61) | **60%** (n=30) |

⇒ **+10.6pp / +11pp，方向与本地一致、幅度约为本地的一半**（本地 +37pp，线上 +11pp——
线上混合了更弱的同族对手，且我们打的是"族的镜像"而不是那一个冻结快照）。

**⇒ 正确的读法是"同族内胜率"，不是分数。** 分数被抽签主导（J9），
而同族胜率是唯一能跨版本比较的量：**它在两个独立样本上都指向 adv 更高更好。**

## 7. 直接头对头（用户提问补做）

同一条种子带（1000–1249）、双座位、每对 **500 局**。v40 与 v41 的 `_ADV_LOOK` **都是 4**
（`experiments/v40/mpx.py` / `experiments/v41/cxd.py` 第 6907 行），所以这三局把 adv 这个变量完全隔离。

| 对局 | 胜率 | 平局 | 均差 | 最差单局 | n |
|---|---|---|---|---|---|
| **adv8 vs v41** | **96.8%** | 0 | +$592 | −$2,444 | 500 |
| **adv12 vs v41** | **97.2%** | 0 | +$726 | −$2,536 | 500 |
| **v41 vs v41（对照：同码自对拍）** | **4.0%** | **460** | **+$0** | −$2,937 | 500 |

**对照那一行是关键**：同码自对拍 500 局里 **460 局平局（92%）**，剩下 40 局是 **20 胜 20 负**、
均差 **$0**。⇒ **镜像台是严格对称的，噪声底是 ±4pp**。

⇒ adv8 的 96.8% 是在 **4.0% 的基线上 +92.8pp**——不是座位不对称、不是镜像假象，
是**一个确定的、系统性的行为差异**（92% 的牌局里同码逐位相同，而 adv8 在 96.8% 的牌局里改变了结果）。

### 7.1 但按 L2，镜像结果只能当筛选器

`claims` L2（用 v30/v31/v32 换来的）：**"打赢自己上一版是筛选器，不是验收器"**——
那三次都是镜像赢 70–94%、真实对手掉胜场。
**所以这一行不构成验收。** 它的价值在于：**它和另外两条独立证据方向一致**，而 v30/v31/v32 那次是矛盾的。

| 证据线 | 构型 | adv8 相对 adv4 |
|---|---|---|
| 头对头 | 镜像（双方同磁带） | **+92.8pp**（vs 4.0% 对照） |
| 对抢跑族 | `tetsutani_cha22`（真对手，自带 adv3） | **+37pp**（48% → 85.4%） |
| 对不抢跑族 | 4 个真对手 | **约 0**（3 个逐位持平，1 个 −5.8pp） |
| 线上同族胜率 | 天梯 `tetsutani` 族 | **+11pp**（49% → 60%） |

**四条线全部同向。** 这与 v30/v31/v32 的"镜像说行、真实说不行"是**相反**的模式。

|---|---|
| 1 | **天梯分不出这个差异**：同码重投实测散布 61–675（中位 380），而 adv4→adv8 只差 224。**昨晚"单调排序"的解读作废。** |
